# STM32F4 Automotive Headlights & Turn Indicators Controller

Firmware prototype for an automotive lighting controller targeting the STM32F413ZH. The system manages headlight beams and turn indicators via CAN bus commands and GPIO switch inputs, with power monitoring over I2C.

## What It Does

- **Headlights** — PWM-controlled high-beam and low-beam outputs. Beam selection is commanded over CAN bus (IDs: `CAN_ID_HIGH`, `CAN_ID_LOW`, `CAN_ID_OFF`).
- **Turn indicators / hazard** — Left, right, and hazard (both) blink patterns driven by GPIO switch inputs, toggled at 100 ms intervals inside a FreeRTOS task.
- **Power monitoring** — INA219 current/voltage sensor read over I2C; reports shunt voltage, bus voltage, current, and power.
- **Self-test on boot** — An event-group flag gates a headlights and indicators test sequence before the RTOS scheduler starts.

## Hardware Architecture

```
                        ┌─────────────────────────────┐
                        │       STM32F413ZH            │
                        │                              │
  CAN Bus ─────────────►│ CAN1          TIM1 CH1/CH2 ──┼──► High / Low Beam (PWM)
                        │                              │
  Left switch ─────────►│ PF12 (GPIO)   PF15 (GPIO) ───┼──► Left indicator LED
  Right switch ─────────►│ PA7  (GPIO)   PE13 (GPIO) ───┼──► Right indicator LED
                        │                              │
  INA219 sensor ────────►│ I2C1 (100 kHz)              │
                        │                              │
  Duty cycle input ─────►│ TIM2 CH1/CH2  (PWM capture) │
  Duty cycle input ─────►│ TIM3 CH1/CH2  (PWM capture) │
                        └─────────────────────────────┘
```

## Technologies Used

| Layer | Details |
|---|---|
| MCU | STM32F413ZH @ 70 MHz (HSE + PLL) |
| RTOS | FreeRTOS via CMSIS-OS v1 — three tasks: Updates, Handler, CAN |
| CAN bus | CAN1, normal mode, interrupt-driven RX FIFO 0 |
| I2C | I2C1 @ 100 kHz, interrupt-driven slave/master mode |
| PWM output | TIM1 CH1 & CH2, 1 kHz, 0–100% duty cycle |
| PWM input capture | TIM2 & TIM3, input capture mode |
| Power monitor | INA219 (Texas Instruments) — 32 V / 2 A calibration |
| HAL | STM32 HAL + LL, generated by STM32CubeMX |

## Project Structure

```
Core/
  Src/

    headlights.c     — headlight state machine (high/low/off)
    indicators.c     — turn indicator blink logic
    ina219.c         — INA219 driver (read/write registers, calibration)
  Inc/

    indicators.h

Middlewares/        — FreeRTOS (generated)
```

## Known Limitations

- **No hardware available for testing.** This is a portfolio/prototype codebase. Logic has been reviewed for correctness but has not been validated on physical hardware.
- The INA219 is read in master mode (`ina219.c`). The driver's master-mode read functions are present but not yet consumed by a runtime task; a periodic polling task is the natural next step.
- A single accept-all CAN filter (ID=0, mask=0) is configured; all incoming IDs reach FIFO0 and are dispatched in software by `StdId`.
- **PA0/PA6 are double-configured.** Both pins are set up as TIM2/TIM3 PWM input-capture channels (see `.ioc`) and are *also* read as digital GPIO in `headlights.c`. The intended role of these pins (beam-emission feedback vs. control input) isn't settled, so the conflicting GPIO read is left in place and flagged here rather than removed.
- Stack sizes for FreeRTOS tasks (128 words each) are minimal and untested under load.
